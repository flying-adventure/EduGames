# Game 2 - Educational Mini Games Collection

## 🎮 프로젝트 소개

**Game 2**는 Streamlit으로 구현된 3가지 교육용 인터랙티브 게임 모음입니다. 아이들이 **수열 패턴 인식**, **날씨 예측**, **가격 계산** 등 기초 수학과 논리 개념을 게임을 통해 재미있게 학습할 수 있습니다.

모든 게임은 **목표 점수(3점) 달성 시스템**으로 진행되며, 연속 정답에 따른 **콤보 시스템**과 **피드백**을 제공합니다.

---

## 🎯 게임 목록

### 1️⃣ 수열 패턴 게임 (Number Pattern Game)

**파일**: `number-pattern.py`  
**배포 링크**: https://pattern-number.streamlit.app/

#### 개요
사용자에게 미리 정의된 10개의 수열 중 하나를 제시하고, 빈칸에 들어갈 숫자를 맞추는 게임입니다. 등차수열(덧셈)과 등비수열(곱셈)의 패턴을 이해하는 데 도움이 됩니다.

#### 수열 유형

**덧셈 패턴 (등차수열) - 5개**
| 문제 ID | 수열 | 차이 | 설명 |
|---------|------|------|------|
| A1 | 10, 11, 12, 13, **?**, 15 | +1 | 1씩 커지는 패턴 |
| A2 | 5, 10, 15, **?**, 25, 30 | +5 | 5씩 커지는 패턴 |
| A3 | 100, 110, 120, 130, **?**, 150 | +10 | 10씩 커지는 패턴 |
| A4 | 23, 25, **?**, 29, 31 | +2 | 2씩 커지는 패턴 |
| A5 | 7, 17, 27, **?**, 47, 57 | +10 | 10씩 커지는 패턴 |

**곱셈 패턴 (등비수열) - 5개**
| 문제 ID | 수열 | 공비 | 설명 |
|---------|------|------|------|
| G1 | 2, 4, 8, **?**, 32 | ×2 | 2씩 곱하는 패턴 |
| G2 | 3, 15, **?**, 375, 1875 | ×5 | 5씩 곱하는 패턴 |
| G3 | 1, 4, 16, **?**, 256 | ×4 | 4씩 곱하는 패턴 |
| G4 | 5, 10, 20, 40, **?** | ×2 | 2씩 곱하는 패턴 |
| G5 | 4, 20, 100, **?**, 2500 | ×5 | 5씩 곱하는 패턴 |

#### 게임 메커니즘
- 10개 문제 중 랜덤으로 선택
- 한 번 풀었던 문제는 중복되지 않음
- 정답 시: +1 점, 오답 시: 0 점
- **목표**: 3점 달성 (3개 정답)
- 게임 종료 후 **정답률** 표시

#### 학습 효과
✅ 수열의 규칙성 인식  
✅ 등차수열(덧셈)과 등비수열(곱셈) 개념 이해  
✅ 패턴 예측 능력 개발

### 2️⃣ 날씨 예측 게임 (Weather Game)

**파일**: `weather.py`  
**배포 링크**: https://third-weather.streamlit.app/

#### 개요
과거 6일의 날씨 패턴을 보고 내일 날씨를 예측하는 게임입니다. 반복되는 패턴을 인식하는 논리력을 기르는 데 효과적입니다.

#### 날씨 패턴 (6가지)

| 규칙 ID | 패턴 | 반복 단위 | 다음 날씨 | 설명 |
|---------|------|---------|---------|------|
| R1 | 🌧️ 🌧️ ☀️ | 3일 | 🌧️ | 비(2회) - 맑음(1회) 반복 |
| R2 | ☁️ 🌧️ ☀️ | 3일 | ☁️ | 구름 - 비 - 맑음 반복 |
| R3 | ☀️ ☁️ | 2일 | ☀️ | 맑음 - 구름 반복 |
| R4 | 🌧️ ☁️ ☁️ | 3일 | 🌧️ | 비 - 구름(2회) 반복 |
| R5 | ☁️ ☀️ 🌧️ | 3일 | ☁️ | 구름 - 맑음 - 비 역순 반복 |
| R6 | 🌧️ ☀️ ☀️ | 3일 | 🌧️ | 비 - 맑음(2회) 반복 |

#### 게임 메커니즘
- 6가지 규칙 중 랜덤 선택
- 과거 6일 날씨 표시 (이모지)
- 내일 날씨를 3가지 선택지 중 선택
- 정답 시: +1 점, 오답 시: 0 점
- **목표**: 3점 달성 (3회 연속 정답)
- 패턴 규칙 설명 제공

#### 학습 효과
✅ 반복되는 패턴 인식  
✅ 시계열 데이터 예측 능력  
✅ 논리적 추론 능력 개발

### 3️⃣ 가격 계산 게임 (Price Game)

**파일**: `price.py`  
**배포 링크**: https://secondgame-pricepredict.streamlit.app/

#### 개요
바구니 크기와 간식 종류에 따른 가격을 계산하는 **단계별 학습 게임**입니다. 기초 산술(곱셈, 덧셈)과 실생활 수학을 연계합니다.

#### 게임 단계

**Step 1: 기본 - 바구니 크기만 고려**
- 기본 규칙: 바구니 1칸 = 100원
- 예시:
  - 바구니 2칸 → 200원
  - 바구니 4칸 → 400원
  - 바구니 6칸 → 600원
- 문제: 바구니 5칸 → ?(정답: 500원)
- 힌트: "바구니가 클수록 가격이 커져요!"

**Step 2: 간식 추가 - 간식 종류에 따른 추가 비용**
- 기본: 바구니 1칸 = 100원
- 추가 비용:
  - 🍬 사탕 = +10원
  - 🍫 초콜릿 = +5원
- 예시:
  - 바구니 5칸 = 500원
  - 바구니 5칸 + 사탕 = 510원
  - 바구니 5칸 + 초콜릿 = 505원
- 문제: 바구니 4칸 + 사탕 → ?(정답: 410원)
- 힌트: "같은 바구니라도, 사탕이나 초콜릿이 들어가면 조금 더 비싸져요!"

**Step 3: 복합 - 크기와 간식 모두 변함**
- 여러 간식 조합 가능
- 예: 바구니 3칸 + 사탕 + 초콜릿 = 315원
- 최고 난이도

#### 게임 메커니즘
- **3단계 난이도** 선택 가능
- 각 단계 3개 예시 제시
- 사용자가 정답 입력 (숫자)
- 정답 시: +1 점, 오답 시: 0 점
- **목표**: 3점 달성
- 피드백: "정답입니다!" / "오답입니다. 정답은 OOO원"

#### 학습 효과
✅ 기초 곱셈과 덧셈  
✅ 실생활 수학 적용  
✅ 논리적 계산 능력

## 🚀 설치 및 실행 방법

### 1. 요구 사항
- Python 3.7+
- Streamlit

### 2. 로컬 설치

```bash
git clone https://github.com/flying-adventure/game2.git
cd game2
pip install -r requirements.txt
```

### 3. 게임 실행

각 게임을 개별적으로 실행할 수 있습니다:

```bash
# 수열 패턴 게임
streamlit run number-pattern.py

# 날씨 예측 게임
streamlit run weather.py

# 가격 계산 게임
streamlit run price.py
```

실행 후 브라우저에서 `http://localhost:8501`로 접속합니다.

## 🎮 게임 플레이 가이드

### 공통 메커니즘
1. **목표 점수**: 각 게임마다 3점 달성
2. **점수 획득**: 정답 시 +1점, 오답 시 0점
3. **게임 진행**: 목표 달성 또는 사용자 포기 시 종료
4. **결과 화면**: 최종 점수, 정답률, 게임 재시작 버튼

### 각 게임별 플레이
- **수열 패턴**: 10개 문제 중 회피 가능 → 3개 정답 달성
- **날씨 예측**: 6가지 규칙 중 무한 반복 → 3회 연속 정답 달성
- **가격 계산**: 3단계 난이도 선택 후 진행 → 3개 정답 달성
